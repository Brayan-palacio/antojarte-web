# 🥐 Antojarte - Menú Digital Interactivo

Aplicación web *mobile-first* desarrollada para el negocio de postres, waffles y antojitos **Antojarte**. Diseñada para ofrecer una experiencia rápida, intuitiva y visualmente atractiva desde cualquier teléfono móvil.

## 🚀 Tecnologías Utilizadas

- **React.js** (Vite)
- **Tailwind CSS** (Estilos modernos y adaptables)
- **WhatsApp Web API** (Formato automático del pedido)
- **Netlify / Vercel** (Despliegue continuo)

## 📌 Características Principales

- 📱 Diseño responsive centrado en dispositivos móviles.
- 🛒 Carrito de compras interactivo en tiempo real.
- 📲 Envío directo de órdenes estructuradas a WhatsApp.
- 🖼️ Catálogo optimizado con imágenes en alta resolución.
